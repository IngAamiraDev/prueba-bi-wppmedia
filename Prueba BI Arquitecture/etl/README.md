# AdBoost Analytics – BI Data Integration Pipeline

## Overview

This project implements a **modular ETL pipeline in Python** to integrate marketing campaign performance data from multiple advertising platforms.

The objective is to **standardize, consolidate, and prepare the data for Business Intelligence analysis**, enabling marketing teams to evaluate campaign performance across platforms and support data-driven budget allocation decisions.

The data sources include campaign performance reports from:

* Google Ads
* YouTube
* Meta Ads

After processing, the pipeline generates a **single consolidated dataset** ready for analytics and dashboarding.

# Project Architecture

The solution follows a **modular ETL architecture** that separates the data pipeline into three main stages:

1. **Extract** – Load raw data from source files
2. **Transform** – Standardize structure and clean the data
3. **Load** – Export the consolidated dataset

This design improves **maintainability, scalability, and code readability**.

```sh
src/
│
├── main.py                 # Orchestrates the ETL pipeline
│
├── extract/                # Data extraction layer
│   ├── googleads.py
│   ├── meta.py
│   └── youtube.py
│
├── transform/              # Data transformation layer
│   ├── standardize.py
│   └── validate.py
│
├── load/                   # Data export layer
│   └── export_csv.py
│
├── utils/
│   └── paths.py            # Project path management
│
temp/
│
├── data/                   # Raw input files
│   ├── Googleads.xlsx
│   ├── Meta.csv
│   └── Youtube.csv
│
└── result/
    └── consolidated_campaign_data.csv
```

# Data Processing Steps

## 1. Data Extraction

Raw campaign data is loaded from three sources:

* **Google Ads** (Excel format)
* **Meta Ads** (CSV)
* **YouTube Ads** (CSV)

Each source is processed through its own extraction module.

## 2. Data Standardization

The datasets are transformed to a common schema with standardized column names and formats.

Final structure:

| Column      | Description                |
| ----------- | -------------------------- |
| plataforma  | Advertising platform       |
| fecha       | Campaign date (YYYY-MM-DD) |
| campaña     | Campaign name              |
| impresiones | Number of impressions      |
| clics       | Number of clicks           |
| costo       | Media spend                |

Dates are converted to **ISO format (YYYY-MM-DD)** and numeric columns are validated.

## 3. Data Validation

The pipeline performs basic quality checks:

* Numeric type validation
* Null handling
* Duplicate removal

These steps ensure the dataset is ready for downstream analytics.

## 4. Data Consolidation

All standardized datasets are merged into a **single unified table**, enabling cross-platform performance comparison.

## 5. Data Export

The final dataset is exported as:

```sh
temp/result/consolidated_campaign_data.csv
```

This file can be used directly in **BI tools or analytics workflows**.
